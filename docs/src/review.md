# 人工维护者审查地图

本页帮助人类维护者理解、手动审查和接管代码。代理审阅、自动测试、覆盖率、Aqua 或包名检查均不能代替人工审查；目前没有人工审核签署，也没有 General 注册或通达信一致性验收。

## 先确认研究合同

状态是**估计的成本概率直方图**，每个 bin 内均匀。历史筹码按成本等比例退出；默认三角峰是典型价，不能从日 OHLC 推得真实 VWAP。无 prior 时首日整日分布 seed；有 prior 时首日也递推。点成交与一字板被摊入所在 bin，因此网格会影响均值、获利比例与分位数。

换手 `0.05=5%`，其流通股/自由流通股/总股本分母由调用者声明。价格基准标签也是调用者的断言。日期检查不验证交易所日历、数据可得时间或未来信息。即使粗细网格的 W1 都为零，也可能把 `5%` 错写成 `5`：本轮独立合成反例的末日均值分别为 `10.5` 与 `20`。

除权采用显式 `p_new=scale*p_old+shift`，先映射昨日状态，再加入当日新成本；今日价格已在新基准。固定复权输入禁止再次非 identity 映射。坐标与概率质量守恒不等于绝对股票数量守恒，配股、新增流通盘和现金分红口径须另作研究定义。

## 按下面顺序看代码

| 文件 | 人工应判断的问题 |
|:--|:--|
| `src/types.jl`、`src/models.jl` | Float64 范围、正质量下溢的失败方式；核对均匀/三角局部积分、峰值、逐笔权重及网格边界规则。 |
| `src/engine.jl` | seed 与 prior、换手饱和、除权先后、支撑覆盖；确认重分箱误差和小质量保护符合承诺。 |
| `src/metrics.jl`、`src/validation.jl` | CDF 与最左逆、等尾集中度、跨网格 W1；微小远端尾部不能因两个 CDF 都舍入为 1 而假报零距离。 |
| `src/data.jl`、`src/reference.jl`、`src/adjustments.jl` | 日期/证券对齐、质量与百分数单位、公司行为因子来源；导入格式刻意限于无引号文本，归一化不能替代来源单位核验。 |
| `examples/analyze_csv.jl` | 路径与链接不覆盖保护、全量计算后写出、写入失败与临时文件清理；本地文件输出不证明供应商对照成立。 |
| `test/`、`docs/`、`.github/workflows/` | 解析答案是否独立、失败路径是否真实、公开 API 文档是否一致、实际发布提交与测试日志是否同源。 |

本版采用严格 Float64 合同：非零输入转成零、归一化/换手递推/除权将应为正的质量下溢到零会报错。极长窗口的旧筹码尾部可能衰减到不可表示值；调用者须显式重定义支持、窗口或另选更高精度实现，不能依赖自动截尾。极小质量的比较与逆 CDF 使用内部精确有理数，公开输出仍为 Float64。存储字段约定只读；直接修改内部向量或并发修改输入不在支持合同内。

## 自动检查的证据与边界

完整包测试、文档、Aqua 与官方包名检查的证据详见包根目录 `DEVELOPMENT_REPORT.md` 与[质量证据](quality.md)。本轮独立审阅先复现抵消、下溢和悬空链接问题，修复后在 macOS arm64 的 Julia **1.10.12 与 1.13.1 各通过 30/30 项定向回归**：数值 17、模拟写失败清理 3、错误单位反例 3、路径保护 7，均退出码 0。符号链接场景在 Unix 测试；Windows 测试保留硬链接、目录和原子写入检查，远程实测尚未完成。

额外独立高精度探针确认低端/高端/内部小质量与普通 CDF 跨零的比较结果；三种除权重叠积分每版 12 项通过，最大质量偏差不超过 `5.55e-17`。这些没有重复计入包测试。模拟 writer 抛错验证了无最终半文件、无临时文件；磁盘写满、系统关闭流失败等 OS 故障未实际诱发。常规 CDF 平台最左逆检查通过。发布须核对最终提交与实际日志同源，不能沿用旧计数。

人工仍需逐项确认上表、复核合法真实数据与因素来源、理解 AI 辅助实现并承担维护责任。远程多系统 CI、真实行情/通达信同口径对照、远程文档部署和 General 审核仍是不同的未完成步骤；本页不签署这些验收。
